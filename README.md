# Turnos Demo · Leank Software

Demo de un **sistema de turnos online** para negocios de servicios (barberías, peluquerías, consultorios, estudios). Es un proyecto de demostración: no contiene datos ni código de ningún cliente.

**Demo en vivo:** https://leandro1905.github.io/turnos-demo/

## Qué hace

- El cliente elige servicio, día y horario, deja sus datos y el turno queda confirmado al instante.
- Los horarios ocupados o ya pasados se bloquean solos, así no se pisan los turnos.
- Vista "Agenda del local": el dueño ve todos los turnos ordenados por día y hora, y puede cancelarlos.
- Los datos se guardan en el navegador (`localStorage`), por eso no necesita servidor.
- Se adapta a celular y a compu.

## Tecnologías

HTML, CSS y JavaScript sin librerías. Un solo archivo (`index.html`).

## Y en un sistema real

Las versiones reales que desarrollo para clientes usan base de datos y backend: recordatorios por WhatsApp, pagos, cuentas de usuario y panel de administración.
